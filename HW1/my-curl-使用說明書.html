Python 命令列工具

my-curl 使用說明書

一個以 Python 與 requests 製作的輕量 HTTP 用戶端。它用接近 curl 的選項，讓你在終端機發送 GET、POST、PUT、DELETE 等 HTTP 請求並查看回應。

1. 專案概覽

用途快速測試網站 API、查看伺服器回應，或練習 HTTP 請求。
進入點mycurl.py；直接以 Python 執行。
相依套件requests >= 2.28.0。
預設行為無資料時送 GET；給資料但未指定方法時自動送 POST。

2. 檔案結構與職責

檔案用途
mycurl.py主程式：解析參數、整理標頭、送出 HTTP 請求、顯示回應與錯誤。
requirements.txt列出所需 Python 套件：requests。
README.md專案的精簡安裝、指令與範例說明。

程式工作流程

讀取命令列參數→驗證/組合 Headers→判斷 HTTP 方法→requests.request()→輸出狀態、標頭與內容

3. 安裝與啟動

請先在命令列切換到 my-curl 專案資料夾，安裝相依套件：

pip install -r requirements.txt

基本語法：

python mycurl.py [選項] <URL>

URL 必須包含協定，例如 https://example.com；省略 http:// 或 https:// 會被視為無效 URL。

4. 指令選項一覽

選項說明範例
-X、--request METHOD指定 HTTP 方法，例如 GET、POST、PUT、DELETE。-X DELETE
-H、--header "Key: Value"加入請求標頭，可重複使用。格式必須含有冒號。-H "Accept: application/json"
-d、--data DATA傳送請求本文。若未指定 -X，程式會自動使用 POST。-d "name=Tom"
-i、--include-headers額外輸出回應狀態列與所有回應標頭。-i
--timeout SECONDS設定逾時秒數，預設為 10 秒。--timeout 30

5. 常用範例

讀取資料（GET）

python mycurl.py https://httpbin.org/get

傳送表單字串（自動 POST）

python mycurl.py -d "name=Tom&age=20" https://httpbin.org/post

明確指定 POST 並加入自訂標頭

python mycurl.py -X POST -H "Content-Type: application/json" -d "{\"name\":\"Tom\"}" https://httpbin.org/post

查看回應標頭

python mycurl.py -i https://httpbin.org/get

呼叫需要較長等待時間的服務

python mycurl.py --timeout 30 https://httpbin.org/delay/3

6. 輸出與錯誤處理

每次成功請求都會先輸出 HTTP 狀態，例如 Status: 200 OK，再輸出回應本文。搭配 -i 時，會在前面增加「Response Headers」區塊。

情況程式行為
無法連線顯示「Failed to connect」並結束。
等待超時顯示逾時秒數並結束。
URL 未含協定提示須加上 http:// 或 https://。
Header 格式錯誤若缺少冒號，例如 -H "Accept"，會說明正確格式是 Key: Value。
其他 requests 例外將錯誤訊息輸出到標準錯誤並結束。

7. 使用注意事項

這是測試工具，請謹慎執行會改變資料的請求。
GET 通常只讀取資料；POST、PUT、DELETE 可能會建立、修改或刪除伺服器資料。確認 URL、方法與資料內容後再執行，尤其不要把帳密或 API 金鑰直接留在共用的命令紀錄中。
  • 多個同名 Header 時，後面指定的值會覆蓋前面的值。
  • -d 會原樣傳給 requests；若 API 要 JSON，請自行設定 Content-Type: application/json 並提供正確 JSON 字串。
  • HTTP 4xx/5xx 回應仍會顯示狀態與本文；程式不會自動把它當成 Python 例外。

8. 一句話速查

python mycurl.py -X <方法> -H "標頭鍵: 標頭值" -d "資料" -i --timeout <秒數> <URL>

只需 URL 就能發 GET；加上 -d 即可快速發 POST；需要看回應標頭時加 -i。
